- بٹن کا پس منظر گہرا سبز ہوگا۔
- بٹن کی تحریر سفید اور واضح ہوگی۔

GitHub پر اپ لوڈ کرنے کا طریقہ:
1) ZIP کو Extract کریں۔
2) GitHub repository میں index.html، style.css اور sw.js کو نئی فائلوں سے Replace کریں۔
3) باقی فائلیں تبدیل کرنے کی ضرورت نہیں؛ موجودہ app.js اسی طرح رہ سکتا ہے۔
4) Commit changes کریں۔
5) ویب سائٹ Chrome میں کھول کر تازہ Reload کریں۔ اگر پرانا رنگ نظر آئے تو Chrome میں site data/cache صاف کرکے دوبارہ کھولیں۔
