VETCARE WORLD — HOMEPAGE / DEPLOYMENT NOTES v13.0
===================================================

The current homepage and responsive stylesheet are:
- index.html
- style.css
- app.js

The package preserves the existing Supabase project configuration and current
member/community code. The menu is intended to contain member details and
Login/Register or Logout on both mobile and desktop.

Deploy the contents of this folder (not the folder itself) to the root of the
GitHub repository on the main branch. Replace matching files, commit, and wait
for GitHub Pages deployment.

After deployment, test:
1. Homepage layout on Android and PC.
2. Three-line menu open/close behavior.
3. Login/Register and Logout from inside the menu.
4. Public knowledge pages and navigation.
5. Member post/like/comment/share actions, and admin moderation if applicable.

Do not rerun Supabase SQL simply as part of deployment. Use the included SQL
files only if a specific database error requires a targeted change.
