VETCARE WORLD — FINAL CLEAN PACKAGE (v21.0)

اس ZIP میں موجودہ ویب سائٹ، Knowledge Centre، Learning Library، Audio Lectures،
Admin Upload/Publish controls، Supabase setup SQL اور SEO فائلیں شامل ہیں۔

اہم خصوصیات:
- عام وزیٹر بغیر Login کے شائع شدہ مواد دیکھ اور ڈاؤن لوڈ کر سکتے ہیں۔
- صرف Supabase میں role = admin والا تصدیق شدہ اکاؤنٹ فائلیں اپ لوڈ کر سکتا ہے۔
- Learning Library کے فولڈرز: Books, Pictures, Articles, Urdu Articles,
  Videos, Audio Lectures, Charts اور Columns۔
- آڈیو فارمیٹس: MP3, M4A, WAV, OGG, AAC, FLAC اور WEBM audio۔
- دستاویزات، تصاویر اور ویڈیوز بھی اپ لوڈ ہو سکتی ہیں۔
- فی فائل زیادہ سے زیادہ 100 MB (Supabase bucket limit بھی 100 MB رکھی گئی ہے)۔
- Publish now منتخب ہو تو فائل فوراً عوام کے لیے شائع ہوگی؛ ورنہ Draft رہے گی۔
- Admin بعد میں Publish، Unpublish یا Delete کر سکتا ہے۔
- موبائل اور PC دونوں کے لیے responsive layout ہے۔

GitHub پر اپ لوڈ:
1) ZIP Extract کریں۔
2) اندر موجود vetcare-world--main فولڈر کھولیں۔
3) اس فولڈر کے اندر کی تمام فائلیں منتخب کریں، فولڈر خود نہیں۔
4) اپنی GitHub repository Aliimran78622/vetcare-world کی main branch کے root میں upload کریں۔
5) پرانی same-name فائلیں Replace کریں اور Commit changes کریں۔
6) GitHub Pages deployment مکمل ہونے کے بعد ویب سائٹ کھولیں۔
7) Admin account سے Login کریں، تین لائنوں والے مینو میں Admin Panel کھولیں۔
8) پہلے ایک چھوٹی MP3 اور PDF سے upload/publish ٹیسٹ کریں۔

Supabase:
- Bucket: vetcare-library
- Table: public.media_library
- اگر Learning Library setup پہلے سے کامیابی سے چلایا ہے تو SQL دوبارہ چلانے سے پہلے
  اپنی موجودہ policies/schema کا جائزہ لیں۔ نئی category/audio policy درکار ہو تو
  LEARNING-LIBRARY-SETUP.sql کو Supabase SQL Editor میں Run کریں۔
- صرف اپنا یا اجازت یافتہ مواد اپ لوڈ کریں۔
