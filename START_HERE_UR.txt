VETCARE WORLD — FINAL PACKAGE v13.0
====================================

یہ ZIP GitHub Pages پر ایک ہی دفعہ اپلوڈ کرنے کے لیے تیار کی گئی ہے۔

کیا درست کیا گیا؟
1. غیر ضروری پرانی اور ڈپلیکیٹ CSS فائلیں ختم کیں۔
2. پرانی متبادل Homepage اور design reference تصاویر ہٹا دیں۔
3. sitemap.txt ختم کرکے درست sitemap.xml رکھا۔
4. Sitemap میں Homepage سمیت تمام 6 عوامی HTML صفحات شامل کیے۔
5. Homepage میں Canonical URL شامل کیا۔
6. robots.txt کو sitemap.xml کے ساتھ درست رکھا۔
7. Service Worker cache کو v13.0 کیا تاکہ پرانی فائلیں دوبارہ نہ آئیں۔
8. Knowledge Centre کے چھ موضوعات کے مضامین فعال کیے:
   بیماری و صحت، خوراک، نسلیں، فارم مینجمنٹ، ویکسینیشن، بچھڑوں کی دیکھ بھال۔
9. Supabase URL، public key اور موجودہ Login/Register، Posts، Likes،
   Comments، Share اور Admin کوڈ محفوظ رکھا۔
10. موبائل اور PC دونوں کے Menu میں ممبر کی معلومات، Login/Register اور Logout رکھے؛ Header سے ممبر کی معلومات ہٹائیں۔
11. پرانی غیر ضروری CSS، متبادل Homepage، design screenshots اور sitemap.txt ختم کیے۔

GitHub پر اپلوڈ:
1. ZIP فائل Extract کریں۔
2. vetcare-world--main فولڈر کھولیں۔
3. اس فولڈر کے اندر موجود تمام فائلیں منتخب کریں۔
4. GitHub repository Aliimran78622/vetcare-world کی main branch کے root میں اپلوڈ کریں۔
5. ایک ہی نام والی پرانی فائل replace کریں، نئی فائلیں بھی اپلوڈ کریں۔
6. Commit changes دبائیں۔

اہم:
- فولڈر خود اپلوڈ نہ کریں؛ فولڈر کے اندر کی فائلیں root میں اپلوڈ کریں۔
- Supabase میں SQL دوبارہ چلانے کی ضرورت نہیں۔
- Google verification HTML فائل ضرور اپلوڈ کریں۔
- اپلوڈ کے بعد Live website اور Login کا ٹیسٹ کریں۔
- Marketplace اور Earning Centre فی الحال واضح طور پر Coming Soon ہیں؛
  ان کے لیے الگ backend اور monetization کام باقی ہے۔
