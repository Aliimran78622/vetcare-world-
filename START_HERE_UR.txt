VETCARE WORLD — CLEAN DEPLOYMENT PACKAGE v13.0
================================================

یہ صاف اور درست کی گئی ZIP فائل ہے۔

اس میں:
1. موجودہ Homepage، CSS اور JavaScript فائلیں شامل ہیں۔
2. Knowledge، Disease & Treatment، About، Contact اور Privacy صفحات شامل ہیں۔
3. sitemap.xml اور robots.txt شامل ہیں۔
4. Google Search Console کی verification HTML فائل شامل ہے۔
5. Supabase کا موجودہ کوڈ اور configuration محفوظ رکھا گیا ہے۔
6. ضروری تصاویر، manifest.json اور sw.js شامل ہیں۔

صفائی:
- پرانی متبادل Homepage ختم کر دی گئی ہے۔
- غیر ضروری style-6.css اور style-7.css ختم کر دی گئی ہیں۔
- sitemap.txt ختم کر دی گئی ہے؛ صرف sitemap.xml موجود ہے۔
- design reference screenshots deploy package سے ہٹا دیے گئے ہیں۔

جانچ:
- app.js کا JavaScript syntax check کامیاب ہے۔
- HTML صفحات کے local links اور images کی فائلیں موجود ہیں۔
- Sitemap میں چھ عوامی صفحات موجود ہیں۔
- robots.txt درست sitemap.xml کی طرف اشارہ کرتا ہے۔
- موجودہ Supabase code محفوظ ہے۔

GitHub پر اپلوڈ:
1. ZIP Extract کریں۔
2. vetcare-world--main فولڈر کھولیں۔
3. فولڈر کے اندر موجود تمام فائلیں منتخب کریں۔
4. GitHub repository Aliimran78622/vetcare-world کی main branch کے root میں اپلوڈ کریں۔
5. پرانی فائلوں کو replace کریں اور Commit changes دبائیں۔
6. GitHub Pages deployment مکمل ہونے دیں، پھر ویب سائٹ کھول کر ٹیسٹ کریں۔

اہم:
- فولڈر کو خود nested folder کے طور پر اپلوڈ نہ کریں؛ اس کے اندر کی فائلیں root میں اپلوڈ کریں۔
- Supabase میں SQL دوبارہ نہ چلائیں، جب تک کوئی خاص error اس کی ضرورت نہ بتائے۔
- ZIP کی local جانچ مکمل ہے؛ Live website اور Supabase actions کا آخری ٹیسٹ deployment کے بعد ہوگا۔
