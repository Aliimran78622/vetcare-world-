VETCARE WORLD — LEARNING LIBRARY UPDATE

اس اپ ڈیٹ میں Learning Library شامل کی گئی ہے۔

اہم خصوصیات:
- تمام وزیٹرز بغیر Login کے شائع شدہ PDF، PPT/PPTX، DOC/DOCX اور تصاویر دیکھ اور ڈاؤن لوڈ کر سکتے ہیں۔
- صرف Supabase میں role=admin رکھنے والا اکاؤنٹ فائل اپ لوڈ، Draft/Publish اور Delete کر سکتا ہے۔
- Books، PDF Lectures & Notes، PowerPoint Slides، Animal Pictures اور Other Resources کی کیٹیگریز۔
- موبائل اور کمپیوٹر دونوں کے لیے Responsive ڈیزائن۔

انسٹال کرنے کا طریقہ:
1) اس ZIP کے اندر موجود تمام فائلیں GitHub repository کے root میں upload/replace کریں۔
2) Supabase > SQL Editor کھولیں۔
3) LEARNING-LIBRARY-SETUP.sql کی پوری عبارت ایک بار Run کریں۔
4) اپنی ویب سائٹ کھولیں اور اپنے Admin اکاؤنٹ سے Login کریں۔
5) تین لائنوں والے مینو میں Admin Panel کھولیں۔
6) Learning Library upload form میں Title، Category، Description اور File منتخب کریں۔ Publish now منتخب ہو تو فائل سب کے لیے دستیاب ہوگی۔

فائل حد: 25 MB فی فائل۔
صرف وہ مواد اپ لوڈ کریں جس کے حقوق آپ کے پاس ہوں یا جسے شیئر کرنے کی اجازت ہو۔
